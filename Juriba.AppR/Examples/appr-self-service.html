Setup Required

This portal requires a local proxy server to communicate with App Readiness. Run the following command first:

cd path\to\powershell-module-appr
node Juriba.AppR/Examples/appr-self-service.js

Then open http://localhost:3000 in your browser.

Source: github.com/juribalimited/powershell-module-appr
