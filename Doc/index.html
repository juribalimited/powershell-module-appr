Juriba App Readiness PowerShell Module

PowerShell module for automating application lifecycle management in Juriba App Readiness. Provides 39+ cmdlets covering application upload, packaging, testing, quality review, and publishing to Intune, MECM, and custom integrations.

Compatibility

Requires PowerShell 7.0+. Tested against App Readiness v5.2 and v6.0 RC.

Requirements

  • PowerShell 7.0+
  • App Readiness instance (v5.2+)
  • API key
