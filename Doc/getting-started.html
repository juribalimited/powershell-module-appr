Getting Started

Installation

Clone the repository and import the module into your PowerShell session.

git clone https://github.com/juribalimited/powershell-module-appr.git
Import-Module ./powershell-module-appr/Juriba.AppR/Juriba.AppR.psd1

Getting an API Key

To authenticate with the App Readiness API, you need an API key. To generate one:

  1. Sign in to your App Readiness web interface.
  2. Navigate to your user profile (top-right menu).
  3. Select API Keys from the profile menu.
  4. Click Generate New Key, provide a description, and copy the key.

Store your API key securely. It is shown only once at creation time.

First Connection

Use Connect-JuribaAppR to establish a session with your App Readiness instance.

Connect-JuribaAppR -Instance "https://appr.example.com" -APIKey "your-api-key"

Sample output:

Connected to Juriba App Readiness at https://appr.example.com

Verify the Connection

Retrieve a short list of applications to confirm everything is working.

Get-JuribaAppRApplicationList -AllUsers -Lite | Select-Object -First 5 | Format-Table id, name, version, manufacturer, status

Sample output:

Your First Workflow

This example uploads an installer, creates an application, and waits for packaging to complete.

Step 1 -- Upload the installer

# Upload an installer
$upload = Send-JuribaAppRSetupFile -FilePath "C:\Installers\7z2407-x64.exe"

Sample output:

Uploading 7z2407-x64.exe (2.1 MB)...
Upload complete.

Uuid        : a3f7c9e2-81d4-4b6a-9e02-5c8d1f3a7b60
FileName    : 7z2407-x64.exe
FileSize    : 2201498
TotalChunks : 1

Step 2 -- Create the application

# Create the application (starts packaging immediately)
$app = New-JuribaAppRApplication -Uuid $upload.Uuid -FileName $upload.FileName `
    -FileSize $upload.FileSize -TotalChunks $upload.TotalChunks -RunImmediately

Sample output:

AppId       : 619
Name        : 7-Zip
Version     : 24.07
Manufacturer: Igor Pavlov
Status      : Packaging

Step 3 -- Wait for packaging to finish

# Watch until packaging completes
$result = Watch-JuribaAppRApplicationStatus -AppId $app.AppId -IntervalSeconds 60
Write-Host "Status: $($result.Status)"

Sample output:

[12:04:31] Watching application 619 -- current status: Packaging
[12:05:32] Status: Packaging
[12:06:33] Status: Packaged
Status: Packaged

Disconnecting

When you are finished, close the session.

Disconnect-JuribaAppR
