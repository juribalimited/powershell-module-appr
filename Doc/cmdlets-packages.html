Package Cmdlets

These cmdlets retrieve packaging information for applications managed by Juriba App Readiness. Use them to inspect which package formats are available, check packaging status, and retrieve detailed metadata for a specific package type.

Get-JuribaAppRApplicationPackage

Synopsis

Gets package information for an application. Returns all available packages or details for a specific package type.

Syntax

# Mode 1 -- All packages for an application
Get-JuribaAppRApplicationPackage -AppId <Int32>

# Mode 2 -- Filtered to a specific package type
Get-JuribaAppRApplicationPackage -AppId <Int32> -PackageType <String>

Parameters

ParameterTypeStatusDescription
-Instance String Optional The URL of the App Readiness instance. Not required if connected via Connect-JuribaAppR.
-APIKey String Optional The API key for authentication. Not required if connected via Connect-JuribaAppR.
-AppId Int32 Required The unique identifier of the application.
-PackageType String Optional Filter to a specific package type. Accepted values: Msi, Msix, IntuneWin, AppV.

Package Type Values

ValueFormatDescription
MsiWindows InstallerTraditional MSI package created by App Readiness.
MsixMSIX / MSIX BundleModern Windows packaging format with containerisation.
IntuneWinIntune Win32Wrapped package for deployment via Microsoft Intune.
AppVApp-V 5.xMicrosoft Application Virtualisation sequence.

When to Use

Use this cmdlet when you need a summary of all package types produced for a given application, or when you want packaging metadata (status, file names, sizes) for a single package type. It calls the allPackages endpoint (Mode 1) or the packaging/information endpoint (Mode 2).

Examples

Example 1 -- List all packages for an application

Get-JuribaAppRApplicationPackage -AppId 101

Example 2 -- Get MSI package details for a specific application

Get-JuribaAppRApplicationPackage -AppId 204 -PackageType Msi
Sample output

Status        : Complete

FileSize      : 104857600

Note: When -PackageType is omitted, the cmdlet calls the allPackages endpoint and returns a summary for every package format. When -PackageType is provided, it calls the packaging/information endpoint and returns richer detail for that single format.

Get-JuribaAppRApplicationPackageDetail

Synopsis

Gets detailed package information for a specific application and package type using the v1 API endpoint.

Syntax

Get-JuribaAppRApplicationPackageDetail -ApplicationId <Int32> -PackageType <String>

Parameters

ParameterTypeStatusDescription
-Instance String Optional The URL of the App Readiness instance. Not required if connected via Connect-JuribaAppR.
-APIKey String Optional The API key for authentication. Not required if connected via Connect-JuribaAppR.
-ApplicationId Int32 Required The unique identifier of the application.
-PackageType String Required The package type to retrieve (e.g. Msi, Msix, IntuneWin, AppV).

When to Use

Use this cmdlet when you need the v1 API response for a package, which includes version-level detail not available from the standard Get-JuribaAppRApplicationPackage endpoint. This is particularly useful for integrations that require the versioned API contract or when you need extended metadata such as build identifiers and packaging timestamps.

Comparison with Get-JuribaAppRApplicationPackage

FeatureGet-JuribaAppRApplicationPackageGet-JuribaAppRApplicationPackageDetail
API endpointapi/packaging/information/{id}/{type}api/v1/application/{id}/package/{type}
List all package typesYes (omit -PackageType)No -- single type only

Version-level metadataLimitedFull
