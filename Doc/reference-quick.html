Juriba.AppR Quick Reference

Single-page cheat sheet for the Juriba.AppR PowerShell module (v0.1.0). All 42 exported cmdlets, lookup tables, and common pipeline patterns.

Connection One-Liner

Connect-JuribaAppR -Instance "https://appr.example.com" -SecretName "AppR-Key"

Common Parameter Note

Every cmdlet accepts optional -Instance and -APIKey parameters to override the stored connection from Connect-JuribaAppR. These are omitted from the table below for brevity.

Common Pipelines

List recent apps with status

Get-JuribaAppRApplicationList -AllUsers | Select-Object id, name, statusDescription | Format-Table

Upload and watch in one pipeline

$u = Send-JuribaAppRSetupFile -FilePath "C:\Installers\App.exe"
$app = New-JuribaAppRApplication -Uuid $u.Uuid -FileName $u.FileName -FileSize $u.FileSize -TotalChunks $u.TotalChunks -RunImmediately
$created = Watch-JuribaAppRApplicationCreation -UploadId $u.Uuid
Watch-JuribaAppRApplicationStatus -AppId $created.applicationId -IntervalSeconds 60

Find apps that passed smoke testing

Get-JuribaAppRTestApplication -AllEnvironments |
    Where-Object { $_.testResult -eq 1 } |
    Select-Object applicationId, applicationName

Get test stats dashboard

Get-JuribaAppRTestStats | Format-List

Publish all ready apps to Intune

Get-JuribaAppRApplicationList -AllUsers |
    Where-Object { $_.statusDescription -eq "ReadyForPublishing" } |
    ForEach-Object {
        Invoke-JuribaAppRPublishIntune -Body @{ applicationId = $_.id; packageType = "IntuneWin" }
    }

Export packages to share via generic integration

$pubs = Get-JuribaAppRGenericIntegrationPublishing -IntegrationId 4
$pubs | ForEach-Object {
    Get-JuribaAppRGenericIntegrationSource -IntegrationId 4 -PublishingId $_.id -SourcePath "\\server\share\packages"
}
